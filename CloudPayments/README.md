# CloudPayments

CloudPayments provides provider-neutral payment orchestration for .NET applications. It supports create, authorize, capture, void, refund, recurring-payment, idempotency, tax-extension, and webhook contracts without depending on CloudCommerce, CloudLogin, CDM, logistics, or booking.

See [the CloudPayments documentation](docs/index.md) for responsibilities, provider integration, examples, and testing guidance.

CloudPayments is part of [Angry Monkey Cloud](https://angrymonkeycloud.com). Development follows the shared [AI instructions](https://github.com/angrymonkeycloud/CloudDocs/blob/main/docs/ai/instructions.md).
