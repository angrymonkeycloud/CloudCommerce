# CloudCommerce Components

CloudCommerce Components provides reusable Blazor components, page compositions, and a default storefront shell over the headless CloudCommerce contracts. Every default slot can be replaced with an application component through `CommerceComponentOptions` without replacing the underlying commerce services.

See [the CloudCommerce UI documentation](../CloudCommerce/docs/ui.md) for full, partial, page-level, component-level, and headless integration.

CloudCommerce Components is part of [Angry Monkey Cloud](https://angrymonkeycloud.com). Development follows the shared [AI instructions](https://github.com/angrymonkeycloud/CloudDocs/blob/main/docs/ai/instructions.md).
