# CloudLogistics

CloudLogistics provides standalone inventory, fulfillment, shipping, carrier, tracking, delivery, and pickup-location contracts. Geographic codes are resolved through CloudGeography rather than duplicated.

See [the CloudLogistics documentation](docs/index.md) for responsibilities, extension points, address integration, and testing guidance.

CloudLogistics is part of [Angry Monkey Cloud](https://angrymonkeycloud.com). Development follows the shared [AI instructions](https://github.com/angrymonkeycloud/CloudDocs/blob/main/docs/ai/instructions.md).
