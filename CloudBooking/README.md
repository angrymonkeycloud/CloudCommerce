# CloudBooking

CloudBooking is a standalone scheduling, availability, capacity, blackout, reservation, cancellation, and rescheduling foundation. It does not require a product or catalog model and works without payments; applications may register the optional payment coordination hook.

See [the CloudBooking documentation](docs/index.md) for responsibilities, examples, extension points, and testing guidance.

CloudBooking is part of [Angry Monkey Cloud](https://angrymonkeycloud.com). Development follows the shared [AI instructions](https://github.com/angrymonkeycloud/CloudDocs/blob/main/docs/ai/instructions.md).
