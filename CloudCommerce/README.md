# CloudCommerce

CloudCommerce is the optional orchestration layer for carts, checkout, orders, discounts, totals, tax, shipping selection, payments, and fulfillment. It uses lightweight product presentations and references; applications retain ownership of their authoritative product and subscription models.

See [the CloudCommerce documentation](docs/index.md) for responsibilities, headless usage, UI customization, extension points, and testing guidance.

CloudCommerce is part of [Angry Monkey Cloud](https://angrymonkeycloud.com). Development follows the shared [AI instructions](https://github.com/angrymonkeycloud/CloudDocs/blob/main/docs/ai/instructions.md).
